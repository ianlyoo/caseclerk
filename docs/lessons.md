# Lessons


- **The sandbox's clock is not yours.** After a filing, the adjudicate simulator answered 409 for about 18 minutes, and the RESOLVED webhook came anywhere from 7 minutes to more than a day later. Build retries, a visible waiting state and dated claims in the docs from the start; never promise a ruling time.
- **Hold the one case you need on camera.** Reserving the demo case in code (API refuses to file it) kept judges and tests from spending it; lifting the hold for one deploy let us record the real approval once.
- **Record narration last, against a finished cut.** One caption per sentence, a row per sentence in the recording sheet, and a scripted splice for retakes made ten re-recorded lines a single rerun. Mix the voice to the listener's taste, not a loudness target: the final sits at −18.6 LUFS by the owner's ear.
- **Same page, same framing.** Dissolves between two shots of the same page must share the camera scale, or the cut reads as a zoom.
- **Publishing is a browser task with captchas.** Devpost's Create project sits behind an invisible reCAPTCHA that automated browsers fail; plan for one short human click and keep every field ready to paste.
