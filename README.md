# CaseClerk

An AI dispute desk for small PayPal sellers. When a buyer opens a PayPal dispute, CaseClerk's agent pulls the order, tracking and transaction history, reads the buyer's messages, decides whether to refund, offer a partial refund or fight, and builds and submits the evidence pack before the deadline, under a seller policy that asks the seller before large actions.

Built for the PayPal AI Hackathon (2026). Work in progress.
